# Development Guide

## Documentation

[SPHEREx Pipelines Documentation](https://spherex-docs.ipac.caltech.edu/pipelines)

To see the version of the documentation for a particular branch, add `v/<branch_name` to the URL link above.

SSDC is using the NumPy docstring format for in-code documentation with Sphinx as the documentation generator.

References:
- [Documenting Python API with docstrings](https://developer.lsst.io/python/numpydoc.html)
- [SPHEREx Sphinx User Guide](https://spherex-docs.ipac.caltech.edu/spherex-sphinx/user-guide/)
